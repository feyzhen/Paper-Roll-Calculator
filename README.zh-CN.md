# 纸卷计算器

一款轻量级网页工具，用于计算特种纸卷的外径、长度、重量及理论卷绕层数。

---

## 功能特性

- **双向计算** — 已知长度求外径，或已知外径求长度
- **参数灵活** — 支持自定义纸芯内径、纸张厚度、纸卷宽度、克重
- **实时结果** — 输入即算，无需手动提交
- **截面示意图** — 自动生成截面图与侧视图，标注关键尺寸
- **外径参考表** — 列出常见外径对应的估算长度与重量
- **中英文切换** — 一键切换界面语言，偏好自动保存
- **状态持久化** — 所有输入参数与语言偏好保存在 `localStorage`，刷新不丢失
- **响应式布局** — 适配桌面、平板和手机屏幕

## 在线使用

直接在浏览器中打开 `index.html` 即可使用，无需安装或构建。

```bash
# 或者用任意静态服务器启动
python -m http.server 8080
# 访问 http://localhost:8080
```

## 计算模式

| 模式 | 说明 |
|------|------|
| 已知长度 → 计算外径 | 输入纸卷长度，自动算出卷绕后的外径 |
| 已知外径 → 计算长度 | 输入目标外径，自动算出对应的纸卷长度 |

## 输入参数

| 参数 | 单位 | 默认值 | 说明 |
|------|------|--------|------|
| 纸芯内径 | mm | 76 | 纸芯管的内径 |
| 纸张厚度 | μm | 45 | 单层纸张厚度 |
| 纸卷宽度 | mm | 425 | 纸卷的轴向宽度 |
| 克重 | g/m² | 30 | 每平方米纸张的克重 |
| 纸卷长度 | m | 10000 | 纸张展开总长度 |
| 纸卷外径 | mm | 760.7 | 卷绕后的外径 |

## 计算公式

**外径（由长度推算）：**

$$OD = \sqrt{ID^2 + \frac{4 \times L \times t \times 1000}{\pi}}$$

**长度（由外径推算）：**

$$L = \frac{\pi \times (OD^2 - ID^2)}{4 \times t \times 1000}$$

**纸张重量：**

$$W = L \times \frac{width}{1000} \times \frac{GSM}{1000} \quad (kg)$$

**理论卷绕层数：**

$$Layers = \lfloor \frac{OD - ID}{2 \times t} \rfloor$$

> 其中：ID = 纸芯内径 (mm)，OD = 纸卷外径 (mm)，L = 长度 (m)，t = 纸张厚度 (μm)，GSM = 克重 (g/m²)

## 技术要点

- **纯前端实现** — 无框架依赖，原生 HTML / CSS / JavaScript
- **i18n 方案** — 通过 `data-i18n` 属性 + 翻译字典实现，支持扩展更多语言
- **SVG 动态绘图** — 截面图和侧视图根据计算结果实时生成，标注随语言切换
- **状态管理** — `localStorage` 保存表单数据与语言偏好，页面刷新自动恢复

## 注意事项

- 计算结果为**理论值**，基于理想卷绕模型
- 重量**不含**纸芯和包装材料
- 实际生产中，卷绕张力和纸张压缩会导致偏差
